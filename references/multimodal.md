# 多模态素材处理

## 可提取的内容

| 输入 | 初步处理 | 必须补看的部分 |
|---|---|---|
| 文本、Markdown、SRT、VTT、CSV | 按行／时间段提取 | 引用上下文、链接与目标页面 |
| DOCX | 段落、表格、页眉页脚、备注和嵌入图片 | 排版含义、文本框、图片OCR及超链接目标 |
| PDF | 每页文本，标记疑似扫描页 | 页面渲染、图片与小字；空文本页需要OCR |
| PPTX | 幻灯片正文和演讲者备注，提取媒体 | 图表、视觉元素、隐藏页和动画语境 |
| XLSX | 工作表单元格文本及公式 | 图表、批注、图片、隐藏信息和公式实际展示结果 |
| 图片 | 尺寸、图片文件清单 | 用视觉能力或可用OCR读取；logo、二维码、人物与授权 |
| 视频 | ffprobe时长／音轨，定时抽帧，音频导出 | 全部口播／字幕、转场、封面、音乐；抽帧遗漏区间补看 |
| 音频 | 基本信息，按需本地转写 | ASR错误、音乐版权及说话语境 |
| 旧版DOC/PPT/XLS等 | 检查可用转换工具 | 未成功转换不得声称全文已读 |

`extract_content.py` 生成 `manifest.json` 与 `extracted.txt`，含原文件哈希、读取错误、文本段落位置、媒体路径及未核验事项。它不自动进行视觉理解、OCR或ASR，不把缺失识别结果填成空白“通过”。压缩文档中的媒体只写到本次输出目录，禁止执行宏或附件程序。

## 视频覆盖

默认每5秒一帧、最多120帧，实际采样区间和覆盖模式写入manifest；这只用于初筛。长片会拉长间隔，不能将采样称为逐帧审阅。高风险片段、字幕变化、极短闪帧、手势、二维码和贴纸应提高密度并结合连续播放。

优先使用用户提供的SRT与原视频校对，再用宿主提供的音频理解／转写或本地ASR。只有取出了WAV不代表听过音轨。没有可用转写能力就报告“画面初筛完成、口播未核验”，继续审可读部分，并请用户补字幕或提供可用转写方式。

## 定位与隐私

位置格式：`文件名 / 第N页 / 段落或单元格 / 00:12.400–00:16.100 / 图片区域`。OCR／ASR不确定词写置信情况，不能用错误识别判违规。原件默认只读；仅在用户要求改稿时创建新版本。用户材料保存在审查工作区，不进入官方规则档案、测试包或公开仓库。
